# BKIT PDCA 기획 및 설계 표준 템플릿

새로운 기능을 구현하거나 리팩토링할 때 본 템플릿 구조를 활용하여 요구사항을 분석하고 설계를 수립합니다.

---

## 1. Plan (기획) 명세

```markdown
### 1.1 기능 명칭 및 배경
- **기능명**: [기능명]
- **배경 및 목적**: 사용자가 겪는 문제점 및 해결 목표

### 1.2 요구사항 분해 (Feature Breakdown)
- [ ] 필수 요구사항 1: ...
- [ ] 필수 요구사항 2: ...
- [ ] 예외 처리 및 방어 가드: ...

### 1.3 사용자 여정 시나리오 (User Journey)
1. 진입: 사용자가 [버튼/탭/행]을 클릭
2. 조작: 마우스 조작(드래그, 줌, 입력 등) 발생
3. 피드백: 0ms 낙관적 반영 또는 플로팅 토스트 표출
4. 완료: 데이터 자동 저장 및 스크롤 위치 보존
```

---

## 2. Design (설계) 명세

```markdown
### 2.1 아키텍처 및 상태 흐름 (State & Data Flow)
- **Props**: 상위 컴포넌트로부터 전달받을 파라미터
- **State**: 컴포넌트 로컬 상태 및 렌더링 최적화(useRef vs useState)
- **Events**: 이벤트 핸들러 및 60FPS RAF 쓰로틀링 적용 여부

### 2.2 UI/UX 명세 (UI/UX Spec)
- **위치 및 위계**: Primary CTA vs Secondary Action 구분
- **반응형/말줄임**: SmartTruncateTooltip 적용 대상 텍스트
- **레이아웃 안정성**: 제로 레이아웃 시프트(고정 높이 컨테이너)

### 2.3 안전성 체크 (Safety Invariants)
- [ ] EGDesk DEV 서버 포트 일치 여부 확인
- [ ] CADON 도면 렌더링 파이프라인(WebGL, 셰이더, 1px 세선) 무손실 보존
- [ ] 사일런트 백그라운드 동기화(전체 로딩 스피너 금지)
```
