# BKIT `gap-detector` (기획-구현 간극 분석기)

기능 구현 전후로 기획서와 실제 코드베이스 간의 차이(간극)를 정밀 진단하는 프레임워크입니다.

---

## 1. 5대 간극 진단 매트릭스

| 간극 유형 | 주요 진단 항목 | 점검 방법 | 해결책 |
| :--- | :--- | :--- | :--- |
| **1. 기능 간극<br>(Functional)** | 기획된 요구사항 누락 여부 | 체크리스트 전수 조사 | 미반영 로직 원자적 구현 |
| **2. 중복 간극<br>(Redundancy)** | 동일 버튼/라벨/정보의 다중 노출 | 화면 전수 캡처 및 DOM 분석 | 상위 1개로 일원화, 서브 제거 |
| **3. 인터랙션 간극<br>(Interaction)** | 드래그 흔들림(Jitter), 캔버스 깜빡임(Flicker) | 마우스 조작 스트레스 테스트 | RAF 60FPS 동기화, 버퍼 고정 |
| **4. 안정성 간극<br>(Safety)** | 스크롤 튕김, 불필요한 전체 로딩창 | CRUD 후 재조회 인터랙션 점검 | 사일런트 동기화(`isSilent=true`) |
| **5. 규칙 간극<br>(Compliance)** | EGDesk 포트, 도면 렌더링 동결 원칙 | `AGENTS.md` 규정 대조 | 하드코딩 제거, 핵심 파이프라인 보존 |

---

## 2. 간극 분석 실행 프로세스

1. **사전 진단 (Pre-check)**:
   - 구현 전, 사용자의 요구사항과 현재 UI 상태를 비교하여 "기능의 필요성 여부"와 "중복 여부"를 사전 판별.
2. **사후 검증 (Post-check)**:
   - 구현 완료 후, 브라우저 실화면 및 DOM 요소들을 대조하여 기획 의도와 1픽셀의 오차도 없는지 최종 검증.
3. **결과 리포트 (Gap Report)**:
   - 발견된 간극, 위험 요인, 해결 결과를 사용자에게 투명하게 한국어로 보고.
